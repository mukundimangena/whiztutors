# Whiz Tutors — brand kit

Everything here is vector-traced from the approved logo sheet, with the lettering converted to shapes, so it looks the same on every device and needs no font installed.

## Logos
| File | Use it for |
|---|---|
| `logo.svg` / `logo.png` | Main logo on white or light backgrounds (documents, email signatures, flyers) |
| `logo-on-dark.svg` / `logo-on-dark.png` | Navy or dark backgrounds (website footer, dark posters) |
| `logo-compact.svg` | Website header and small spaces (no tagline, no divider) |
| `logo-compact-on-dark.svg` | Same, on dark backgrounds |
| `logo-mono.svg` | One-colour printing, stamps, faxes, embroidery |
| `logo-white.svg` | All-white, on photos or strong colour |
| `mark.svg` / `mark.png`, `mark-mono.svg`, `mark-white.svg` | The atom symbol on its own |

## Icons
| File | Use it for |
|---|---|
| `favicon.svg`, `favicon.ico`, `favicon-32.png` | Browser tab icon (bolder strokes so it reads at 16–32px) |
| `apple-touch-icon.png` | iPhone/iPad home-screen icon |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | Android home-screen / web app manifest |
| `app-icon-512.png`, `app-icon-dark-512.png` (+ .svg) | Social media profile pictures, WhatsApp Business avatar |
| `og-image.jpg` | Preview image when a link to the site is shared (WhatsApp, Facebook, LinkedIn) |

## Colours
| Name | Hex | Use |
|---|---|---|
| Violet | `#7C3AED` | Gradient start, accents |
| Blue | `#3B82F6` | Gradient end |
| Sky | `#60A5FA` | Light accent on dark backgrounds |
| Navy | `#0F172A` | Text, dark backgrounds |
| Mist | `#E5E7EB` | Borders, light backgrounds |
| Indigo (website links & buttons) | `#4F46E5` | Between violet and blue; dark enough for readable text on white |

Brand gradient: `linear-gradient(135deg, #7C3AED, #3B82F6)`.

## Type
- Logo and headings: **Montserrat** ExtraBold/Black (free, Google Fonts)
- Body text: **Inter** Regular/Medium

## Rules of thumb
- Leave clear space around the logo at least the height of the "W".
- Smallest size: logo 120px wide on screen (25 mm in print); below that use the mark or compact logo.
- Don't stretch, recolour outside the palette, add shadows, or put the colour logo on busy photos (use `logo-white.svg`).
